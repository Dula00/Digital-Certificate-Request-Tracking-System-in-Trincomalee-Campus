# Digital Certificate Request Tracking System in Trincomalee Campus

## 📌 Project Description

### The Problem
Currently, the process of requesting and tracking academic certificates at Trincomalee Campus is handled manually. This leads to delays, lack of transparency, and difficulty for students to know the status of their requests.

### The Solution
The **Digital Certificate Request & Tracking System** is a web-based solution designed to digitize this entire process. It allows students to submit requests online and enables the administration to manage and update the status in real-time.
